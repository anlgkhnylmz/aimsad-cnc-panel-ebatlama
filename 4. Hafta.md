## Bağlam

Önceki haftalarda tehlikeleri ve veri yollarını bulduk. Bu hafta **tek bir kritik olayı** merkeze alıp iki yöne bakıyoruz:
- **Sol taraf:** Bu olaya hangi **nedenler** yol açar? (Önleyici bariyerler)
- **Sağ taraf:** Olay olursa hangi **sonuçlar** doğar? (Hafifletici bariyerler)

Papyonun düğümü kritik olaydır: **"Operatörün eli, testere hareket hâlindeyken kesim hattına girer."**

~~~mermaid

    N1["Neden 1<br/>Bariyer köprülenmiş"] --> O
    N2["Neden 2<br/>Fren süresi uzamış"] --> O

    N4["Neden 4<br/>?"] --> O
    O(("KRİTİK OLAY<br/>El kesim hattında,<br/>testere hareketli"))
    O --> S1["Sonuç 1<br/>Parmak/el kaybı"]
    O --> S2["Sonuç 2<br/>?"]
    O --> S3["Sonuç 3<br/>Üretimin durması,<br/>soruşturma"]

~~~

## Kavram

- **Önleyici bariyer:** Neden ile olay arasına girer (örneğin bariyer köprülemeye karşı kodlu manyetik sensör).
- **Hafifletici bariyer:** Olay ile sonuç arasına girer (örneğin hızlı fren, ilk yardım, olay müdahalesi).
- **Bariyer bozucusu (escalation factor):** Bir bariyeri zayıflatan durum (eğitimsiz personel, üretim baskısı, paylaşılan parola).
- Siber bir neden, fiziksel bir sonuca giden **aynı papyonun** bir koludur. Ayrı bir analiz gerektirmez.

---

## Görev A — Papyonu tamamlayın

İki "?" kutusunu doldurun, sonra her nedene **en az bir önleyici**, her sonuca **en az bir hafifletici** bariyer ekleyin.

| Neden | Önleyici bariyer | Bariyeri bozan etken |
|---|---|---|
| Bariyer köprülenmiş | | |
| Fren süresi uzamış | | |
| Uzaktan muting alanı genişletilmiş | | |
| (sizin nedeniniz) | | |

| Sonuç | Hafifletici bariyer | Sorumlu |
|---|---|---|
| Parmak/el kaybı | | |
| (sizin sonucunuz) | | |
| Üretimin durması | | |

## Görev B — Sorular

1. Hangi nedenin önünde **yalnız bir** bariyer var? Bu neden tehlikelidir?
2. Neden 3 (uzaktan değişiklik) için önleyici bariyer **teknik** mi olmalı, **prosedürel** mi? İkisi birden mi?
3. "Üretim baskısı" hangi bariyerleri birden bozar? Yönetim seviyesinde hangi önlem alınır?
4. Papyonunuzdaki bariyerlerden hangisi **periyodik test** gerektirir? Test sıklığını önerin.

> **Bu föyün çıktısı:** Papyon Diyagramı + Bariyer Listesi → *Teknik Dosya · Bölüm 4: Risk Azaltma*

<details>
<summary><b>Örnek cevaplar (önce kendiniz doldurun)</b></summary>

**Eksik kutular:** Neden 4 → Kesim listesi hatası nedeniyle beklenmeyen bir hareket (itici, operatör parçayı alırken hareket eder). Sonuç 2 → Fırlayan küçük parça nedeniyle göz veya yüz yaralanması.

| Neden | Önleyici bariyer | Bozan etken |
|---|---|---|
| Bariyer köprülenmiş | Kodlu ve izlenen bağlantı, köprülemeyi algılayan Safety PLC teşhisi, kilitli pano | Çevrim süresi baskısı, denetim eksikliği |
| Fren süresi uzamış | Periyodik durma süresi ölçümü, frenin kendi kendini izlemesi | Bakım planının atlanması |
| Muting alanı uzaktan genişletilmiş | Safety PLC'ye uzaktan yazma kapalı, parametre imzası | Paylaşılan uzak destek parolası |
| Kesim listesi hatası | PLC'de makullük kontrolü, minimum parça ölçüsü | Paylaşılan klasöre herkesin yazabilmesi |

| Sonuç | Hafifletici bariyer | Sorumlu |
|---|---|---|
| El kaybı | Hızlı fren + ilk yardım ekibi + acil müdahale planı | Emniyet sorumlusu |
| Göz yaralanması | Koruyucu gözlük zorunluluğu, parça tutucu | Vardiya amiri |
| Üretimin durması | Olay prosedürü, yedek parça, kanıt koruma | Üretim müdürü |

1. Genellikle "muting alanı uzaktan genişletilmiş" nedeni. Teknik bariyer yoksa tek koruma, insanların kurallara uymasıdır. Tek bariyer başarısız olursa olayın önünde hiçbir engel kalmaz.
2. İkisi birden. Teknik: uzaktan yazma kapalı, parametre imzası. Prosedürel: değişiklik onayı ve iki kişi kuralı. Teknik bariyer insan hatasını, prosedür ise teknik açığı telafi eder.
3. Köprüleme, muting genişletme ve bakım erteleme. Önlem: performans hedeflerine emniyet göstergeleri eklemek ve "dur" yetkisini operatöre açıkça vermek.
4. Bariyer fonksiyon testi (vardiya başı), durma süresi ölçümü (6 ayda bir), Safety PLC parametre imzası karşılaştırması (her bakım sonrası).
